# Cadastro de Carros
**RF**
- [ ] Deve ser possível cadastrar um novo carro

**RN**
- [ ] Não deve ser possivel cadastrar um carro com uma placa já existente
- [ ] Não deve ser possivel alterar a placa de um carro já cadastrado.
- [ ] O carro deve ser cadastrado por padrão como disponivel.
- [ ] O cadastro so pode ser feito por um administrador.

# Listagem de carros
**RF**
- [ ] Deve ser possivel listar todos os carros disponiveis.
- [ ] Deve ser possivel listar todos os carros disponiveis pelo nome da categoria.
- [ ] Deve ser possivel listar todos os carros disponiveis pelo nome da marca.

**RN**
- [ ] Não é necessário estar logado no sistema.

# Cadastro de especificação no carro
**RF**
- [ ] Deve ser possivel cadastrar uma especificação no carro.
- [ ] Deve ser possivel listar todas as especificações.

**RN**
- [ ] Não deve ser possível cadastrar uma especificação para um carro não existente.
- [ ] Não deve ser possivel cadastrar uma especificação já existente no mesmo carro.
- [ ] O cadastro so pode ser feito por um administrador.

# Cadastro de imagem do carro
**RF**
- [ ] Deve ser possivel cadastrar a imgem de um carro.
- [ ] Deve ser possivel listar todos os carros.

**RN**
- [ ] O usuário deve poder cadastrar mais de uma imagem para o mesmo carro

# Aluguel de carro.
**RF**
- [ ] Deve ser possivel cadastrar um aluguel.

**RN**
- [ ] O aluguel deve ter duração minima de 24h.
- [ ] Não deve ser possível cadastrar mais de um aluguel para o mesmo usuário
- [ ] Não deve ser possível cadastrar mais de um aluguel para o mesmo carro.
